# Booknotes

## Description 
It is a local hosted dynamic website. It is used to save your notes along with ratings for the books you have read.

The books saved can be sorted in acending or decending order of their rating also.

User can **Edit** or **Delete** the existing entries of books too.

For saving a book notes/entry user have to provide its name, notes, rating and with the use Of OpenSource Books Library **(i.e. https://openlibrary.org/)** and API the website automatically fetches its **Book cover, Author name and Author picture** using the book's **ISBN** number without needing of user to know them all. 

## Languages and Services used:
* Node JS 
* Express JS
* EJS
* HTML, CSS, Javascript
* Postgres SQL
* Bootstrap
* Application Programming Interface (API)
